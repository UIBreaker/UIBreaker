### 🚀 Về bản thân

- 💻 **Trọng tâm hiện tại:** Phát triển các ứng dụng Web Full-stack hiện đại, tối ưu hóa giao diện (UI/UX) và kiến trúc hệ thống dữ liệu thời gian thực.
- 🛠️ **Thế mạnh:** Xây dựng giao diện responsive mượt mà với **React / Next.js / Tailwind CSS**, tích hợp API và chuẩn hóa luồng nghiệp vụ.
- 🎮 **Sở thích kỹ thuật:** Thiết kế logic trò chơi thẻ bài/chiến thuật bằng **Lua**, tối ưu thuật toán và cấu trúc dữ liệu game 2D.
- 🎯 **Mục tiêu:** Tạo ra các sản phẩm số tinh gọn, hiệu năng cao và giải quyết bài toán thực tế hiệu quả.
